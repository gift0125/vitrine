# 2026-10-20

## 1. 控制层退场：标题向上收走，胶囊散成尘

用户提：**控制栏消失时做鸿蒙的粒子效果，标题栏消失时有个向上的动画。**

### 1.1 决定（两条动作分开做）

| 谁 | 怎么退 | 为什么 |
|---|---|---|
| 标题带 | `translateY(-12px)` + 淡出，`.36s cubic-bezier(.22,.78,.28,1)`；traffic `-7px` | 它是**信息** |
| 顶部压暗 | `.42s` 一并淡掉 | 本来只为托住标题，标题走了就没有存在理由 |
| 控制胶囊 | **散成尘**：本体 `.18s` 淡出，形体交给 340 颗粒子 | 它是**材质** |
| 回场 | 聚 520ms 先走，胶囊 `.26s` + `.07s` 延迟淡入 | 聚是"响应"不该让用户等；且要在淡入完成前成形，否则像被擦掉 |

方向统一（向外 + 向上），读者才觉得是"一起退场"。

**不做「滑出窗口」**：标题贴顶边 25px，滑出去要 25px+，位移太大像抽屉，而且文字会在窗口
边缘被切一半。-12px 足够读出方向。

### 1.2 粒子参数（`DUST`）

- 340 颗；只在 **12px 轮廓带**取点，按 `exp(d/5.04)` 拒绝采样（d = 圆角矩形 SDF）
- 沿 **SDF 梯度**（= 外法线）外推 `24 × (0.45~1.0)`，叠浮力 `16·e²`，再加切向 `sin(u·5+φ)`
- 散 `1-(1-u)³` / 聚 `(1-u)²`；alpha `.55 × (1-u)^1.5`；半径 0.4~1.6，三档混合
- `lighter` 混合；32×32 径向渐变 sprite 逐帧 `drawImage`

### 1.3 这轮真正踩到的三条

- **别用 `arc` 填圆画粒子**：硬边读成噪点。但也**别逐帧建渐变**（60fps 直接垮）——
  预渲染一张 sprite 再 `drawImage` 拉大小。
- **粒子密度必须按轮廓带加权**。第一版均匀撒，看着像满屏星点，读不出"是那根条在散"。
  修法两层：贴边权重量级远大于内部 + `delay` 随贴边程度走（边先松、中心最后走）。
- **headless 的 `--virtual-time-budget` 不推进 CSS transition**（只推进 `setTimeout`）：
  `getComputedStyle` 永远读到起始值；而 `?bare=1` 又带 `transition:none!important`。
  所以动效只能靠**端点态截图 + `transitionProperty/Duration` 读数**验证，别指望截到中间帧。
  （粒子能截，是因为 `?dust=` 是同步算好一帧直接画。）

另外：canvas 在 `fit()` 缩放下跟着缩，整页截图里 1px 粒子会缩没——要看 1:1 就 `?bare=1`。
