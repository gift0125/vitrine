## 首屏三态写进 HTML 原型（design/preview/index.html）

原状态：`preview/index.html` 只有视频播放态（主窗 / 歌单 / OSD），首屏只存在于画布 + `frames/*-firstrun-*.png`。

做法：

- 新增**独立窗口** `#winFirst`（560×440），和 `#win` 并列放在 `.win-holder` 里；
  `body.view-first` 决定露哪个。`fit()` 改成按视图取设计尺寸（`VIEWS = {main:1280×800, first:560×440}`），
  `?bare=1` 截首屏就是 560×440。
- 工具条第一排加了「视图」（主窗 / 首屏），首屏选中时第二排换成 三态 + 平台。
  默认仍是主窗，老链接（`?idle=1` / `?layers=…` / `?panel=…`）行为不变。
- URL：`?view=first&fr=recent|empty|drop&os=mac|win`。
- 图标（文件夹 / 链接 / 继续 / 行 / 下载 / Win 控件）**全部换成画布导出的 SVG 路径**（`export_nodes format=svg`）。
  导出的 path 是「描边转填充」后的轮廓，四周各多 0.55（描边一半）——塞进 14×14 viewBox 要用
  `<g transform="translate(.65 2.45)">` 这类补偿，不能直接贴。手画近似形会差一圈。
- 应用图标 `icons/chroma-256.png` base64 内联（8.4KB），保持单文件。

量出来的三条（都写进 README 了）：

1. 投放区边框是 **1.5px** `#8839EF` 50%（帧上三行全是纯色），不是 1px；`打开串流` 那种才是 1px。
2. 引导块行高 **21（fs15）/ 17（fs12）**，靠 ink 间距 30.5 / 27 反推的；居中后整体比"纯居中"低 1px，
   用 `padding-top:2px` 补。补完文字 ink 和帧逐行对齐（292 / 322.5 / 349.5）。
3. **帧里没有 `打开文件` 的投影，画布节点里有**（`21:13` 的 DROP_SHADOW）。单独导这个按钮能看到投影，
   是整帧导出那次丢了 effect。HTML 按节点做了，所以和帧比会多一圈紫晕——不是 HTML 错。

验收：`?view=first&fr=…&bare=1` 截 2x 逐像素比 6 帧 → 空 / 拖入中 1.4–1.6%，最近打开 3.3%，
残差全是字形（画布 Noto Sans SC vs 本机 PingFang SC，ink 位置对得上）。JS 无报错；
切视图 / 三态 / 平台的点击用 headless 注入脚本跑过一遍，全部生效。

顺手记的两个坑：

- 本机没有 PIL，量图用自写的 zlib+filter 解码（`/tmp/measure.py`），别指望 `Image`；
  画布导出的 PNG 是 **ct=3 索引色**，解码要读 PLTE/tRNS，否则拿到的是调色板下标。
- 别用 `--window-size=560,440` 判断截出来的尺寸：Read 工具显示会缩到 1080 宽，实际 1120；
  一律先打印 PNG 的真实尺寸再量。
- 补：PIL 在 `~/.workbuddy/binaries/python/envs/default/bin/python` 里（12.2.0），
  `normalize-frames.py` / `make-overview.py` 都用它跑；managed `versions/3.13.12` 那个没有 PIL。
